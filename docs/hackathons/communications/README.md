# Hackathon communications

These eleven drafts are reusable correspondence, not sent messages or records of outcomes.
Replace every bracketed placeholder with verified information and apply each template's
send condition. If a fact is unavailable, state that it is pending or omit it; never convert
an invitation into acceptance, a receipt into eligibility, or selection into prize payment.

Use the current event configuration and finalized official terms for dates, time zones,
forms and prize conditions. Keep event updates limited to recipients who may receive them;
verify consent/communication preferences and provide an approved private response channel.
Do not expose recipients through shared To/CC lists. Store filled messages, responses,
contact details, application data and send records outside this public repository.
No sender, mailing list, bulk email service or delivery automation is implemented.
